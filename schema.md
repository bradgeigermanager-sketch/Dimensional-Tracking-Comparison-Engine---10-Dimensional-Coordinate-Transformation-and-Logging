# USM Schema

The canonical schema lives at:

- [`usm/schema/usm_schema.json`](../usm/schema/usm_schema.json)

It defines:

- `TenDNode`
- `EntanglementBond`
- `ViewManifold`
- Version metadata
- Log entry structures

These map directly to:

- [`models.py`](../usm/core/models.py)
- [`logging_models.py`](../usm/core/logging_models.py)
